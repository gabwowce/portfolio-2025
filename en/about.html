How I work

I think about the whole system

I look beyond the screen I'm building. I consider the data flow, the API, states, user permissions and how a decision will affect other parts of the system.

I understand the problem first

When something doesn't work or works badly, I look for the cause first. Only then do I change the code. This matters most with existing and larger systems.

I can work with existing code

Not everything has to start from scratch. I can get to grips with someone else's code and existing architecture, and improve or extend the system step by step.

I keep up with modern technology

I use AI tools in development and build AI features into products themselves, from simple LLM features to agents that can use the system's API.
