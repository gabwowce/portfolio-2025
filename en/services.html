What I do

  • I build it from frontend to API and database

  • API and backend
  • Authentication and permissions
  • Data model
  • Integrations
  • AI features

Improving an existing system

  • I clean up tangled, repeated code and improve performance

03 —

Price and warranty

Fixed price

For every project I give a fixed price, agreed before we start: you pay for the result, not for hours, and there are no surprises on the invoice. The price depends on the scope, the integrations and what the system needs to do.

3-month warranty

If within 3 months of launch a bug turns up that comes from my implementation, I fix it at no extra cost.

What you can expect

  • A fixed, agreed price
  • No unexpected extra work
  • Progress you can always see
  • Decisions with a purpose
  • UX that's comfortable to use
  • User guides, plus video guides if needed
  • A 3-month warranty on my work
