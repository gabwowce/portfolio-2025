Loyalty management system — B2B backoffice

Web · client project · screens not shown

An internal system in daily use: loyalty cards, cardholders, organisations and transactions. Its users are the company's own staff, not end customers, so everything turns on permissions, auditability and data accuracy.

The hard part. Not the interface — keeping data and logic consistent with a live backend that keeps changing. API types are generated from the backend schema, so every schema change has to be re-synced before a user runs into it. Bulk card actions have two completely different paths that both need equal support. Multi-step forms with dynamic fields produced stale-closure validation bugs. And migrating promotions off the old system, with its priority rules, meant backfilling the data before anything could be switched over.

My role. Not just the frontend. I scope and hand off work to the backend developer, agree the API contracts and steer the project as a whole — and I built the early stage alone, before a backend developer joined.

How it's built
  • React + TSbackoffice UI
  • RTK Querytypes from schema
  • AG Gridlarge tables
  • REST APIlive backend
  • ~27 routes
  • 8 domains
  • 2 × ~2200 translation keys
  • Roles and audit log

TikMaker — video editor with AI voiceover

Web · internal tool · 2026 · AI inside

A tool I built for my own TikTok / Reels / Shorts content: a scene storyboard, a timeline with separate text, visual and audio tracks, and a real render to MP4 — not a mockup, projects export as actual files.

Where the AI is. ElevenLabs text-to-speech (the multilingual model, which handles Lithuanian) is wired in through a server-side endpoint of my own, so the API key stays on the server and never reaches the browser. The decision that mattered: the generated voice track is written into the same audio manifest as every other sound effect. So it automatically gets a timeline row, a waveform, trim/split and volume — there is no separate "voice" pipeline to maintain.

Honestly. This is an internal tool I use myself, not a product for sale. I show it because it demonstrates how an AI service gets wired into a real product: key on the server, output folded into the existing data model rather than bolted on the side.

How it's built
  • React + TSeditor, timeline
  • Serverio endpointAPI key stays here
  • ElevenLabstext -> speech
  • Garsų manifestasvoice = just another track
  • Remotionrender to MP4
