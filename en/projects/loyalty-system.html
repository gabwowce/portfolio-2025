Loyalty management system

B2B back office · team project · 2026

What it is
An admin system for business loyalty programmes: cards, customers, promotions and coupons managed in one place. The project is confidential, so data in the screenshots is masked and the description is short.
Status
Actively developed.
01 —

Cards and customers

Everything about a card and its owner on one screen: the list on the left, the selected record on the right.

02 —

Promotions

Promotions can be created and tested before they go live.

Technical side

Role
Lead frontend developer in a team with a backend developer, plus part of the backend work.
Decisions
  • The API client is generated from the backend's OpenAPI description, so frontend and backend types always match.
  • Menus, tabs and route protection are built from a single definition based on the user's permissions.
  • Integration tests check screens with different role permissions.
Scale
3 languages · ~730 frontend tests
Stack
React, TypeScript, RTK Query, AG Grid, Tailwind CSS, shadcn/ui · .NET, SQL Server · Vitest, Playwright
