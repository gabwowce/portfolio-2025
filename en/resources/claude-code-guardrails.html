Claude Code Guardrails

Claude Code can run shell commands on its own. These are the five hooks that stop it from running the dangerous ones — and the reasoning behind each one.

The problem

An agent that can run arbitrary shell commands will, sooner or later, try to run one you did not mean to approve. Guardrails catch that before it executes — not after.

What's inside

  • A .claude/settings.json with five hook definitions
  • A guard.sh script the hooks call into
  • A plain-language explanation of what each hook blocks and why
  • Drop-in setup — no build step, no dependencies
