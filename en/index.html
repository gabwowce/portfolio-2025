GET TO KNOW ME

A few things you can expect when working with me.

I THINK IN WHOLE SYSTEMS

I don't just look at the screen I'm building. I consider the data flow, the API, states, user permissions, and how a change affects the rest of the system.

I UNDERSTAND THE PROBLEM FIRST

When something doesn't work, or works poorly, I look for the cause first. Only then do I change the code. That matters even more on larger, already-running systems.

I CAN WORK WITH EXISTING CODE

You don't have to start over. I can read someone else's code and architecture, then improve or extend the system step by step.

I KEEP UP WITH MODERN TOOLS

I use AI tools in my own workflow, and I build AI features into the products themselves — from simple LLM features to agents that can call a system's own API.
