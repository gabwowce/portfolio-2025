How I can help

A new system from scratch

When you need a working product, not a web page.

I help pin down the solution, design the interface and build the system from frontend to API and database.

Includes

  • React / TypeScript
  • API and backend
  • Authentication and permissions
  • Data model
  • Integrations
  • AI features

Improving an existing system

When the system works but is slow or hard to develop further.

First I find where the problem is, then I fix what actually gets in the way.

Includes

  • Performance
  • Refactoring
  • Finding and fixing bugs
  • UX problems
  • API optimisation
  • AI integrations

New features for an existing system

When the product doesn't need a rewrite.

I get to know the existing code and build new features without breaking what already works.

Includes

  • New modules
  • Frontend features
  • Backend features
  • New API endpoints
  • Integrations
  • AI agents and LLMs
