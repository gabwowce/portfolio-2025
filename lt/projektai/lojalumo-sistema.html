Lojalumo valdymo sistema

B2B backoffice · komandinis projektas · 2026

Kas tai
Administravimo sistema verslo lojalumo programoms: kortelės, klientai, akcijos ir kuponai valdomi vienoje vietoje. Projektas konfidencialus, todėl ekrano kopijose duomenys uždengti, o aprašymas trumpas.
Būsena
Aktyviai vystoma.
01 —

Kortelės ir klientai

Visa informacija apie kortelę ir jos savininką viename ekrane: sąrašas kairėje, pasirinktas įrašas dešinėje.

02 —

Akcijos

Akcijas galima sukurti ir išbandyti dar prieš jas paleidžiant.

Techninė dalis

Ką darėme
Pagrindinė frontend programuotoja komandoje su backend programuotoju, taip pat dalis backend darbų.
Sprendimai
  • API klientas generuojamas iš backend'o OpenAPI aprašo, todėl frontend ir backend tipai visada sutampa.
  • Meniu, skirtukai ir maršrutų apsauga kuriami iš vieno aprašo pagal naudotojo leidimus.
  • Integraciniai testai tikrina ekranus su skirtingais rolių leidimais.
Mastas
3 kalbos · ~730 frontend testų
Stackas
React, TypeScript, RTK Query, AG Grid, Tailwind CSS, shadcn/ui · .NET, SQL Server · Vitest, Playwright
