Techninė dalis

Rolė
Pagrindinė frontend programuotoja komandoje su backend programuotoju, taip pat dalis backend darbų.
Sprendimai
  • API klientas generuojamas iš backend'o OpenAPI aprašo, todėl frontend ir backend tipai visada sutampa.
  • Meniu, skirtukai ir maršrutų apsauga kuriami iš vieno aprašo pagal naudotojo leidimus.
  • Integraciniai testai tikrina ekranus su skirtingais rolių leidimais.
Mastas
3 kalbos · ~730 frontend testų
Stackas
React, TypeScript, RTK Query, AG Grid, Tailwind CSS, shadcn/ui · .NET, SQL Server · Vitest, Playwright
